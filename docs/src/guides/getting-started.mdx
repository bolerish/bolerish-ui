# Introduction

bolerish/ui is a React design system built with StyleX. Components, semantic tokens and Foundations guidance share decisions about surfaces, typography, spacing and interaction.

## Start with the package

Install `@bolerish/ui`, import its CSS once, and use the compiled components in your app. React and React DOM 19 are required. Basic usage does not need a StyleX compiler or generated component files.

Follow [Installation](/docs/installation) for the first component, [Theming](/docs/theming) for light and dark modes, and [Styling](/docs/styling) for customization with CSS or StyleX.

## Compose beyond the component list

Use an existing component's `variant` and `size` first. When building a new screen, use [Foundations](/docs/foundations/overview) to choose roles and tokens, and [Patterns](/docs/patterns/search-and-filter) to connect controls into a task. These rules also apply to UI that is not included in this package.

Read [Typography](/docs/foundations/typography) for text hierarchy and [Gradient](/docs/foundations/gradient) for content-colored backgrounds. Each component page includes examples, usage guidance and API information.

## For coding agents

Start with [llms.txt](/llms.txt) for the English reference index. It links to Foundations, component guidance and source-derived API references. Check the installed package's types before choosing props; reference documents do not add APIs.

## Package updates

Updates arrive through npm. Existing copied component files remain local and are not updated by installing a newer package. See [Changelog](/docs/changelog) for release notes and migration guidance.

# 소개

bolerish/ui는 React와 StyleX로 만든 디자인 시스템입니다. 컴포넌트, 의미 기반 토큰, Foundations 지침이 표면·타이포그래피·간격·상호작용에 대한 기준을 공유합니다.

## 패키지로 시작하기

`@bolerish/ui`를 설치하고 CSS를 한 번 가져온 뒤 컴파일된 컴포넌트를 사용합니다. React와 React DOM 19가 필요합니다. 기본 사용에는 StyleX 컴파일러나 컴포넌트 파일 생성이 필요하지 않습니다.

[설치](/docs/installation)에서 첫 컴포넌트를 적용하고, [테마](/docs/theming)에서 라이트·다크 모드를, [스타일링](/docs/styling)에서 CSS와 StyleX를 이용한 확장을 확인하세요.

## 목록에 없는 화면 만들기

기존 컴포넌트의 `variant`와 `size`를 먼저 선택합니다. 새로운 화면은 [Foundations](/docs/foundations/overview)로 역할과 토큰을 정하고, [Patterns](/docs/patterns/search-and-filter)를 참고해 여러 컨트롤을 하나의 작업으로 연결합니다. 패키지에 없는 UI를 만들 때도 같은 기준을 사용합니다.

글의 위계는 [Typography](/docs/foundations/typography), 콘텐츠 색상을 배경에 적용하는 방법은 [Gradient](/docs/foundations/gradient)를 확인하세요. 각 컴포넌트 문서에는 예제, 사용 지침과 API 정보가 있습니다.

## 코딩 에이전트와 사용하기

[llms.txt](/llms.txt)는 영어 참조 문서의 시작점입니다. Foundations, 컴포넌트 지침과 소스에서 생성한 API 참조로 연결됩니다. 속성을 선택할 때는 설치된 패키지의 타입을 확인하세요. 참조 문서가 새로운 API를 추가하지는 않습니다.

## 패키지 업데이트

업데이트는 npm으로 배포합니다. 과거에 복사한 컴포넌트 파일은 로컬에 남으며 패키지 업그레이드로 갱신되지 않습니다. 변경과 이관 안내는 [변경 기록](/docs/changelog)을 확인하세요.
