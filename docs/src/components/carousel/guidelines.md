## 사용 가이드

전체 비교보다 개별 항목을 둘러보는 일이 중요할 때 사용합니다. 한눈에 비교해야 하면 그리드를 선택합니다.

> 필수 안내를 뒤쪽 슬라이드에만 넣지 않습니다.

## 현재 슬라이드와 옆 슬라이드

`<Carousel slideRatio={[70, 20]}>`는 gap을 제외한 가용 너비를 현재 슬라이드와
옆 슬라이드의 보이는 부분에 70:20으로 나눕니다. 70%·20%를 각각 지정하는 API가
아니며, 합계가 100일 필요는 없습니다. 예를 들어 gap이 8px인 360px 뷰포트에서는
현재 슬라이드 약274px, 옆 부분 약78px입니다. 모든 슬라이드의 폭은 같습니다.

생략하면 기존 100% 슬라이드와 gap=0을 유지합니다. 비율을 지정하면 start 정렬과
`spacingRoleVars.inlineGap`을 기본값으로 사용합니다. gap을 바꿀 때는 Carousel의
`xstyle`에서 `--nuee-carousel-gap`을 설정해야 실제 gap과 폭 계산이 일치합니다.
비율은 가로 방향 전용이고 양수 두 개를 받습니다. Embla의 options와 plugins는
계속 사용하며 align을 덮어쓰면 보이는 부분이 양옆으로 나뉠 수 있습니다.

작은 화면에서는 첫 슬라이드가 읽기 어려워지지 않도록 비율을 [1, 0]으로 바꾸는
대신 slideRatio를 생략하거나 CSS 미디어 조건으로 Item의 flexBasis를 100%로
덮어씁니다. Previous/Next 버튼은 Tab과 Enter/Space로 조작할 수 있습니다.
root 방향키를 전역으로 가로채지 않아 슬라이드 안의 입력·링크 동작을 유지합니다.
