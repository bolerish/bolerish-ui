## 사용 가이드

### 주요 속성

| 속성    | 기본값    | 값                              | 용도                                          |
| ------- | --------- | ------------------------------- | --------------------------------------------- |
| `level` | 필수      | `1`, `2`, `3`, `4`, `5`, `6`    | 문서 구조에 맞는 HTML 제목 단계를 선택합니다. |
| `size`  | `section` | `page`, `section`, `subsection` | 제목 단계와 별개로 시각적 크기를 선택합니다.  |

`level`은 필수이며 1부터 6까지의 HTML 제목 단계를 정합니다. `size`는 `page`, `section`, `subsection` 중 선택하고 기본값은 `section`입니다. 세 크기는 각각 `fontSizeXl`, `fontSizeLg`, `fontSizeMd`에 `fontWeightSemibold`와 `lineHeightTight`를 조합합니다.

> 크게 보이게 하려고 제목 단계를 바꾸지 않습니다. 예제는 지원하는 h1–h6을 모두 보여줍니다. 실제 페이지에서는 문서 구조에 맞는 단계만 사용합니다.
