## 사용 가이드

### 사용할 때

중요한 결과를 낳는 행동을 진행할지 결정해야 할 때 사용합니다. 편집 폼은 [Dialog](?path=/docs/components-dialog--docs), 완료한 결과는 Toast나 화면 안의 안내로 전달합니다. 일상적인 행동마다 확인을 요구하지 않습니다.

### 결정할 내용 설명하기

삭제할 대상을 `AlertDialogTitle`에 명시하고, 삭제 범위나 복구 가능 여부처럼 결정에 필요한 정보만 `AlertDialogDescription`에 덧붙입니다. 취소와 함께 “프로젝트 삭제”처럼 구체적인 행동을 제공합니다. 데이터 손실을 모호한 “확인”으로 확정하게 하지 않습니다.

@bolerish/ui의 `AlertDialogAction`은 파괴적 행동의 `Button` 스타일을 사용합니다. 일반적인 주요 확인 버튼이 아닙니다. `AlertDialogAction`과 `AlertDialogCancel`은 모두 닫기 컨트롤이며 저장이나 요청 처리를 구현하지 않습니다.

### 요청과 복구

대화상자가 데이터를 삭제해 주지는 않습니다. 확인 행동에 애플리케이션 로직을 연결합니다. 비동기 요청은 열림 상태를 제어해 실패 안내와 재시도를 유지할 수 있게 합니다. 요청 중에는 중복 제출을 막습니다.

### 작업 위치로 돌아가기

> 성공하면 삭제한 항목을 제거합니다. 원래 실행 버튼이 사라졌다면 남은 항목이나 목록 제목으로 초점을 옮깁니다. 마지막 항목을 삭제했다면 다음에 할 수 있는 일을 안내합니다. 취소하면 실행 버튼으로 초점을 돌려줍니다.
