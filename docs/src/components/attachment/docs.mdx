## 사용 가이드

### 주요 속성

| 속성                      | 기본값       | 값                       | 용도                                         |
| ------------------------- | ------------ | ------------------------ | -------------------------------------------- |
| `orientation`             | `horizontal` | `horizontal`, `vertical` | 파일 정보의 가로·세로 배치를 선택합니다.     |
| `size`                    | `default`    | `default`, `sm`, `xs`    | 첨부 항목의 여백과 미디어 크기를 선택합니다. |
| `AttachmentMedia.variant` | `icon`       | `icon`, `image`          | 파일 아이콘 또는 이미지 미리보기 영역입니다. |

이름으로 파일을 식별하고 크기·형식으로 맥락을, 상태로 업로드나 처리 결과를 알립니다.

> 줄인 파일 이름만으로 비슷한 파일을 구분하게 하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### Props

| Prop                      | Default      | Values                   | Meaning                                           |
| ------------------------- | ------------ | ------------------------ | ------------------------------------------------- |
| `orientation`             | `horizontal` | `horizontal`, `vertical` | Arranges file content horizontally or vertically. |
| `size`                    | `default`    | `default`, `sm`, `xs`    | Controls attachment spacing and media size.       |
| `AttachmentMedia.variant` | `icon`       | `icon`, `image`          | File icon or image preview treatment.             |

Use the name for identification, size or type for context, and status for upload or processing results.

> Do not make a shortened filename the only way to distinguish similar files.

</LocaleContent>
