## 사용 가이드

길이가 정해진 코드에 사용하고 코드를 보낸 곳을 안내합니다. 재전송과 만료 안내는 입력 가까이에 둡니다.

> 붙여 넣기와 자동 완성을 허용합니다. 코드를 외워 한 글자씩 다시 입력하게 하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Use it for a fixed-length code and explain where the code was sent. Keep resend and expiry information near the input.

> Allow paste and autofill; do not require users to remember and retype the code character by character.

</LocaleContent>
