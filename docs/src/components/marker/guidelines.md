## 사용 가이드

### 주요 속성

| 속성      | 기본값    | 값                               | 용도                                                           |
| --------- | --------- | -------------------------------- | -------------------------------------------------------------- |
| `variant` | `default` | `default`, `border`, `separator` | 기본 상태 안내·경계가 있는 안내·콘텐츠 사이 구분을 선택합니다. |

날짜나 읽지 않은 구간처럼 의미 있는 경계를 흐름 안에 표시합니다.

> 행동이나 설명이 필요한 메시지를 마커로 대신하지 않습니다.
