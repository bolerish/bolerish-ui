## Usage guidelines

### Props

| Prop      | Default   | Values                           | Meaning                                                        |
| --------- | --------- | -------------------------------- | -------------------------------------------------------------- |
| `variant` | `default` | `default`, `border`, `separator` | Default status, bordered notice, or separator between content. |

Use a marker for a meaningful boundary, such as a date or unread section, without interrupting the sequence.

> Do not use a marker in place of a message that needs an action or explanation.
