## 사용 가이드

### 주요 속성

| 속성      | 기본값    | 값                           | 용도                                              |
| --------- | --------- | ---------------------------- | ------------------------------------------------- |
| `variant` | `default` | `default`, `outline`, `soft` | 기본·윤곽·은은한 배경으로 선택 상태를 표현합니다. |
| `size`    | `md`      | `sm`, `md`, `lg`             | 토글 높이와 여백을 선택합니다.                    |

굵게 쓰기처럼 유지되는 모드에 사용합니다. 한 번 실행하는 명령은 `Button`, 설정은 `Switch`를 사용합니다.

> 접근성에 전달되는 상태와 눌린 모양을 일치시킵니다.

선택은 강조색 대신 중립 `bgCurrent`와 안쪽 경계로 표시합니다. `soft` 그룹은 기존 중립
raised 면과 그림자로 구분합니다. 체크 아이콘을 일괄 추가하지 않으며 `aria-pressed`는
primitive가 전달합니다. 비활성화되어도 선택 면·경계를 지우지 않고 포커스 표시는 유지합니다.
