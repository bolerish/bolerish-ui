## 사용 가이드

패널은 자리를 유지하고 내부 내용만 스크롤해야 할 때 사용합니다. 주 문서는 일반 페이지 스크롤을 우선합니다.

> 중첩 스크롤은 탐색을 어렵게 할 수 있습니다. 키보드로 모든 내용에 접근할 수 있는지 확인합니다.

<LocaleContent locale="en">

## Usage guidelines

Use it where a panel must retain its place while its contents scroll. Prefer normal page scrolling for the main document.

> Nested scrolling can make navigation harder; verify keyboard access to the full content.
