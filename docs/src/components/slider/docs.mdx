## 사용 가이드

음량처럼 대략적인 조정에 사용합니다. 정확한 값 입력이 중요하면 숫자 입력도 제공합니다.

> 드래그만으로 값을 바꾸게 하지 않습니다. 키보드와 드래그 없는 조작 방법을 유지합니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Use it for approximate adjustment such as volume. Add a numeric input when entering an exact value matters.

> Dragging must not be the only way to change the value; preserve keyboard and pointer alternatives.
