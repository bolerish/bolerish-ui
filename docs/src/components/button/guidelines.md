## 사용 가이드

### 주요 속성

| 속성      | 기본값    | 값                                                                      | 용도                                                                                 |
| --------- | --------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `variant` | `primary` | `primary`, `secondary`, `outline`, `ghost`, `destructive`               | 주요 행동·보조 행동·윤곽·최소 강조·위험 행동을 구분합니다.                           |
| `size`    | `md`      | `sm`, `md`, `lg`, `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`, `icon-xl` | 일반 버튼 높이 또는 아이콘 전용 크기입니다. 아이콘 버튼에는 aria-label이 필요합니다. |
| `shape`   | `default` | `default`, `square`, `circle`                                           | 기본 모서리·정사각형·원형을 선택합니다.                                              |
| `align`   | `center`  | `start`, `center`, `end`, `space-between`                               | 버튼 안의 콘텐츠를 정렬합니다.                                                       |

### 사용할 때

현재 작업에서 제출·저장·생성·변경을 실행할 때 `Button`을 사용합니다. 다른 페이지나 내려받을 파일로 이동할 때는 링크를 사용합니다. 유지되는 선택 상태는 `Checkbox`나 `Switch`로 표현합니다. 눌린 듯한 버튼 모양만으로는 그 상태를 설명하기 어렵습니다.

### 강조 수준 선택

| 변형          | 사용할 때                                    | 피할 때                                             |
| ------------- | -------------------------------------------- | --------------------------------------------------- |
| `primary`     | 저장처럼 작업을 다음 단계로 진행하는 행동    | 같은 그룹의 모든 행동을 똑같이 강조할 때            |
| `secondary`   | 은은한 배경으로 구분할 보조 행동             | 주요 행동과 같은 강조가 필요할 때                   |
| `outline`     | 투명 배경과 테두리로 구분할 보조 행동        | 테두리를 모든 컨트롤에 반복할 때                    |
| `ghost`       | 행이나 도구 모음에서 맥락이 분명한 보조 행동 | 복잡한 화면에서 유일한 완료 행동을 약하게 표시할 때 |
| `destructive` | 데이터를 지우거나 복구 비용이 큰 행동        | 일반적인 취소나 수정 가능한 입력 오류를 표시할 때   |

작업 영역마다 주요 행동 하나를 기준으로 시작합니다. 대화상자는 별도 작업 영역이므로 배경 화면에 주요 행동이 있어도 확인 버튼을 강조할 수 있습니다. 반복되는 행은 보통 secondary나 ghost를 사용해 모든 행이 주의를 끌지 않게 합니다.

### 크기와 배치 선택

기본값인 `md`에서 시작합니다. 밀도가 높은 행이나 도구 모음은 `sm`, 주변 폼이나 배치에 더 큰 컨트롤이 필요하면 `lg`를 사용합니다. 관련 버튼끼리는 크기를 맞춥니다. 강조 수준을 정하는 대신 크기만 키우지 않습니다.

아이콘만 있는 행동에는 `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`, `icon-xl`를 사용하고 `aria-label`을 제공합니다. 뜻이 익숙하지 않은 아이콘은 글자 이름을 함께 표시합니다. 모양은 외곽선을 바꾸며 행동의 의미를 대신하지 않습니다.

행동은 영향을 받는 콘텐츠 가까이에 두고 비슷한 화면에서 순서를 유지합니다. Content Row는 제목과 행동을 첫 줄에 맞추므로 설명 유무에 따라 위아래 여백을 수동 보정하지 않습니다.

버튼 내부 정렬은 `align`으로 지정합니다. 기본값은 `center`이며 `start`, `end`,
`space-between`을 지원합니다. `start`와 `end`는 글 방향을 따릅니다. 정렬 차이가
보이려면 콘텐츠보다 넓은 너비가 필요합니다. `space-between`은 직접 자식 사이의
남는 공간을 나누므로 이름과 뒤쪽 아이콘을 양끝에 배치할 때 사용합니다.

### 이름과 처리 상태

“변경 사항 저장”, “프로젝트 삭제”처럼 동작과 필요한 대상을 씁니다. 폼 안에서는 제출에 `type="submit"`, 나머지 행동에 `type="button"`을 명시합니다.

> `Button`은 `loading` 속성을 제공하지 않습니다. 애플리케이션에서 처리 상태와 중복 제출을 제어하고, 처리 중 문구나 텍스트 상태를 동반한 `Spinner`를 표시합니다. 비활성 버튼만으로 행동할 수 없는 이유를 설명하지 않습니다.
