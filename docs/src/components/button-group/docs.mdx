## 사용 가이드

함께 사용하는 행동을 묶고 관련 없는 페이지 행동은 그룹 밖에 둡니다.

> 버튼을 묶는 것만으로 선택 상태가 생기지는 않습니다. 유지되는 선택에는 `Toggle` Group을 사용합니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Group actions people use together, and keep unrelated page actions outside the group.

> Visual grouping does not create a selection state. Use `Toggle` Group for persistent choices.

</LocaleContent>
