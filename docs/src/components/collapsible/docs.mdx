## 사용 가이드

선택적으로 펼칠 영역 하나에 사용합니다. 제목이 있는 여러 영역이 한 묶음이면 `Accordion`을 사용합니다.

<LocaleContent locale="en">

## Usage guidelines

Use one disclosure for one optional region. Use `Accordion` when several titled sections form a set.

> Do not collapse an error or instruction required to finish the visible task.

</LocaleContent>
