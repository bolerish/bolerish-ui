## Usage guidelines

### Props

| Prop                      | Default   | Values                        | Meaning                                            |
| ------------------------- | --------- | ----------------------------- | -------------------------------------------------- |
| `variant`                 | `default` | `default`, `muted`, `outline` | Default, muted background, or outlined row.        |
| `size`                    | `default` | `default`, `sm`, `xs`         | Controls row spacing and minimum height.           |
| `ContentRowMedia.variant` | `icon`    | `icon`, `avatar`, `image`     | Sizes leading media for an icon, avatar, or image. |

Use it for items people scan individually. Use `Table` when comparing several attributes across rows.

> Let the row handle first-line alignment instead of adding padding to compensate for each description.
