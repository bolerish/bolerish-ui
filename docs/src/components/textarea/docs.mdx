## 사용 가이드

### 주요 속성

| 속성           | 기본값  | 값              | 용도                                                                    |
| -------------- | ------- | --------------- | ----------------------------------------------------------------------- |
| `disabled`     | `false` | `boolean`       | 입력과 크기 조절을 막고 사용할 수 없는 상태로 표시합니다.               |
| `aria-invalid` | `false` | `true`, `false` | 유효하지 않은 값을 오류 경계로 표시합니다. 오류 설명도 함께 연결합니다. |

댓글·설명 등 여러 줄 값에 사용합니다. 짧은 한 줄 값은 `Input`을 사용합니다.

> 고정 높이 때문에 입력한 내용이나 다음 행동이 가려지지 않게 합니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### Props

| Prop           | Default | Values          | Meaning                                                          |
| -------------- | ------- | --------------- | ---------------------------------------------------------------- |
| `disabled`     | `false` | `boolean`       | Disables editing and resizing and shows an unavailable state.    |
| `aria-invalid` | `false` | `true`, `false` | Shows invalid input. Also associate a descriptive error message. |

Use it for comments, descriptions, and other multi-line values. Use `Input` for a short single-line value.

> Do not let a fixed height conceal entered text or the controls needed to continue.

</LocaleContent>
