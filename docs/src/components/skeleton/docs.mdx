## 사용 가이드

뒤에 나타날 콘텐츠와 비슷한 모양으로 표시합니다. 결과의 모양을 예상할 수 없는 행동에는 `Spinner`를 사용합니다.

> 로딩 상태를 알릴 방법을 제공하고 실패하면 스켈레톤을 오류 안내로 바꿉니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Match the placeholder to the content that will replace it. Use `Spinner` for an action whose result has no predictable shape.

> Keep a loading announcement available and replace the skeleton with an error state if loading fails.

</LocaleContent>
