## Usage guidelines

### Props

| Prop      | Default     | Values                   | Meaning                                                      |
| --------- | ----------- | ------------------------ | ------------------------------------------------------------ |
| `variant` | `segmented` | `segmented`, `underline` | Marks the active view with a segmented surface or underline. |

Use short labels that distinguish peer views. Use navigation links when each destination is a separate page.

> Do not use tabs as numbered steps when one step depends on completing another.

Selected grouped surfaces also use an inset `strokeAction` boundary for contrast on Fog and inverse backgrounds.
