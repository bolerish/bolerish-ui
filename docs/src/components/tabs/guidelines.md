## 사용 가이드

### 주요 속성

| 속성      | 기본값      | 값                       | 용도                                                  |
| --------- | ----------- | ------------------------ | ----------------------------------------------------- |
| `variant` | `segmented` | `segmented`, `underline` | 묶음 안의 선택 면 또는 밑줄로 현재 보기를 표시합니다. |

같은 수준의 보기를 구분하는 짧은 이름을 사용합니다. 목적지가 별도 페이지라면 탐색 링크를 사용합니다.

> 앞 단계를 마쳐야 다음 단계로 갈 수 있는 절차를 탭으로 표현하지 않습니다.

묶음 안의 선택 면은 `strokeAction` 안쪽 경계도 사용해 Fog와 반전 배경에서 구별됩니다.
