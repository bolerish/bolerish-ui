## 사용 가이드

### 주요 속성

| 속성           | 기본값    | 값                  | 용도                                                                    |
| -------------- | --------- | ------------------- | ----------------------------------------------------------------------- |
| `variant`      | `outline` | `outline`, `inline` | 일반 폼 경계 또는 주변 글자에 맞춘 인라인 편집입니다.                   |
| `disabled`     | `false`   | `boolean`           | 입력을 막고 사용할 수 없는 상태로 표시합니다.                           |
| `aria-invalid` | `false`   | `true`, `false`     | 유효하지 않은 값을 오류 경계로 표시합니다. 오류 설명도 함께 연결합니다. |

한 줄은 `Input`, 여러 줄은 `Textarea`, 정해진 값 중 선택은 선택 컨트롤을 사용합니다.

> 플레이스홀더는 입력하면 사라집니다. 필드 이름은 계속 보여 줍니다.

### 문장과 목록 안에서 편집하기

짧은 인라인 편집에는 `variant="inline"`을 사용합니다. 글자 크기와 색상은
주변 콘텐츠를 따르며 키보드 초점 표시와 오류 표시는 유지합니다. 여러 입력을
하나의 경계로 묶으려면 `InputGroup`을 선택합니다. 화면마다 테두리와 초점
스타일을 새로 정의하지 않습니다.
