## 사용 가이드

실제 작업에서 계산한 값을 표시합니다. 남은 양을 모르면 `Spinner`를 사용합니다.

> 불확실한 진행을 정확하게 보이게 하려고 백분율을 만들어 표시하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Use a value derived from actual work. Use `Spinner` when the amount remaining is unknown.

> Do not invent percentages to make uncertain progress look precise.
