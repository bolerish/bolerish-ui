## 사용 가이드

### 주요 속성

| 속성                | 기본값    | 값                            | 용도                                                  |
| ------------------- | --------- | ----------------------------- | ----------------------------------------------------- |
| `variant`           | `default` | `default`, `muted`, `outline` | 기본·약한 배경·윤곽으로 행을 구분합니다.              |
| `size`              | `default` | `default`, `sm`, `xs`         | 행의 여백과 최소 높이를 선택합니다.                   |
| `ItemMedia.variant` | `icon`    | `icon`, `avatar`, `image`     | 앞쪽 미디어를 아이콘·아바타·이미지 크기로 배치합니다. |

항목을 하나씩 훑어보는 목록에 사용합니다. 행 사이에서 여러 속성을 비교한다면 `Table`을 사용합니다.

> 설명마다 여백으로 보정하지 않고 행이 제공하는 첫 줄 정렬을 사용합니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### Props

| Prop                | Default   | Values                        | Meaning                                            |
| ------------------- | --------- | ----------------------------- | -------------------------------------------------- |
| `variant`           | `default` | `default`, `muted`, `outline` | Default, muted background, or outlined row.        |
| `size`              | `default` | `default`, `sm`, `xs`         | Controls row spacing and minimum height.           |
| `ItemMedia.variant` | `icon`    | `icon`, `avatar`, `image`     | Sizes leading media for an icon, avatar, or image. |

Use it for items people scan individually. Use `Table` when comparing several attributes across rows.

> Let the row handle first-line alignment instead of adding padding to compensate for each description.

</LocaleContent>
