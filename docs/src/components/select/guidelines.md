## 사용 가이드

### 사용할 때

상태나 팀처럼 목록을 읽고 알아볼 수 있는 정해진 값을 선택할 때 사용합니다. 목록을 닫은 뒤에도 선택한 값이 보여야 합니다.

### 다른 컴포넌트를 고를 때

- 항목이 많거나 익숙하지 않아 입력으로 찾는 편이 빠르면 [Combobox](?path=/docs/components-combobox--docs)를 사용합니다.
- 목록을 열지 않고 선택지를 비교해야 한다면 [Radio Group](?path=/docs/components-radio-group--docs)을 사용합니다.
- 복제·삭제처럼 값을 선택하는 대신 명령을 실행한다면 Dropdown Menu를 사용합니다.

### 이름과 선택 전 상태

현재 값과 별개로 필드 이름을 제공합니다. 플레이스홀더는 선택을 안내하며 이름을 대신하지 않습니다. 기본값은 유효하고 유용한 시작점일 때만 정합니다. 동의나 비용이 발생하는 선택을 임의로 미리 적용하지 않습니다.

> `SelectTrigger`에는 @nuee/ui의 `size`나 `variant` 속성이 없습니다. `Button`의 속성을 전달하기보다 기본 컨트롤 크기를 유지합니다.
