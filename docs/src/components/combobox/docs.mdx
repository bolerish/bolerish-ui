# Combobox

Help people find a value by typing instead of scanning a long list.

Use search to narrow the candidates, then show which value was selected. Use `Select` when a short list is enough.

> The search text and selected value are different states; arbitrary text does not automatically create a new item.

## 사용 가이드

### 주요 속성

| 속성                                  | 기본값     | 값                  | 용도                                               |
| ------------------------------------- | ---------- | ------------------- | -------------------------------------------------- |
| `ComboboxInput.variant`               | `outline`  | `outline`, `inline` | 일반 검색 필드 또는 콘텐츠 안의 인라인 편집입니다. |
| `ComboboxInput.startAddon / endAddon` | 설정 안 함 | `ReactNode`         | 입력 앞뒤에 보조 콘텐츠를 배치합니다.              |

### 사용할 때

사람이나 프로젝트처럼 글자를 입력해 후보를 좁힌 뒤 항목을 선택할 때 사용합니다. 목록을 훑는 것으로 충분하면 [Select](/docs/components/select), 자유로운 텍스트 값이면 `Input`을 사용합니다.

### 검색과 선택 구분

입력 중인 검색어와 확정된 선택값을 구분합니다. 임의의 글자를 입력하면 새 항목이 만들어진다고 안내하지 않습니다. 새 항목을 만들려면 애플리케이션에서 생성 행동과 저장 처리를 제공해야 합니다. 비슷한 이름을 구별할 수 있도록 후보 이름을 구체적으로 표시합니다.

### 결과와 상태

검색이 끝났지만 일치하는 항목이 없을 때 `ComboboxEmpty`를 사용합니다. 서버에서 후보를 가져온다면 로딩·실패·오래된 응답은 애플리케이션에서 처리합니다. 빈 목록만으로 세 상태를 모두 설명하지 않습니다. 실패 후에도 검색어를 유지해 다시 시도할 수 있게 합니다.

> 플레이스홀더와 별개로 입력에 접근 가능한 이름을 제공합니다. 포인터 선택뿐 아니라 키보드 선택과 값 지우기도 확인합니다. 결과 페이지의 동작은 [Search and Filter](/docs/patterns/search-and-filter)를 확인합니다.

### 앱 검색과 보조 요소

`ComboboxInput`의 `variant="inline"`은 앱 검색처럼 주변 화면에 이어지는 입력에
사용합니다. `startAddon`과 `endAddon`에 검색 엔진 버튼이나 단축키 안내를 넣을
수 있습니다. 기본 검색 아이콘·열기 버튼을 대체하더라도 입력 이름과 키보드
옵션 선택을 유지하고, 버튼에는 별도의 접근 가능한 이름을 제공합니다.

## Usage guidelines

### Props

| Prop                                  | Default   | Values              | Meaning                                                 |
| ------------------------------------- | --------- | ------------------- | ------------------------------------------------------- |
| `ComboboxInput.variant`               | `outline` | `outline`, `inline` | Outlined search field or inline editing within content. |
| `ComboboxInput.startAddon / endAddon` | Unset     | `ReactNode`         | Places supporting content before or after the input.    |

### When to use

Use `Combobox` when users select an item by narrowing a list with text, such as finding a person or project. Use [Select](/docs/components/select) when scanning the list is sufficient, or `Input` when the value is unrestricted text.

### Search is not selection

Distinguish the text being typed from the selected value. Do not promise that arbitrary text creates a new item: creation requires an explicit application flow. Keep option labels specific enough to distinguish similar names.

### Results and states

Use `ComboboxEmpty` for a completed search with no matches. If results come from a server, manage loading, failures, and stale responses in the application; an empty list does not explain all three. Preserve the query after a failure so the user can retry.

> Keep the input's accessible name separate from its placeholder. Verify keyboard selection and clearing as well as pointer selection. See [Search and Filter](/docs/patterns/search-and-filter) for results-page behavior.

### App search and supporting elements

Use `ComboboxInput variant="inline"` for search that blends into the surrounding
screen. `startAddon` and `endAddon` can replace the default search icon and open
button with an engine picker or shortcut hint. Retain an input label, keyboard
option selection and accessible names for addon buttons.
