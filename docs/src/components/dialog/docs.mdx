# Dialog

Give a short task a focused space while preserving the page the user came from.

Use it for a bounded edit or decision. Use a page for work that needs independent navigation or a shareable address.

> Closing must have a defined effect on unsaved input, regardless of how the dialog is dismissed.

## 사용 가이드

### 사용할 때

이름 변경이나 관련 필드 몇 개 수정처럼 범위가 분명한 작업에 사용합니다. 페이지 안에서 바로 수정해도 작업이 명확하다면 인라인 편집을 선택합니다. 탐색·공유할 URL·많은 콘텐츠가 필요한 작업은 별도 페이지로 만듭니다.

### Dialog와 Drawer 선택

콘텐츠와 가용 공간에 가장자리 패널이 적합하면 [Drawer](/docs/components/drawer)를 선택합니다. 둘 다 배경 작업을 중단할 수 있습니다. 등장 방향이 배경 조작 가능 여부를 결정하지는 않습니다. 터치 기기라는 이유만으로 `Drawer`로 바꾸지 않습니다.

콘텐츠를 편집하는 대신 중요한 결과를 낳는 행동을 확인해야 한다면 [Alert Dialog](/docs/components/alert-dialog)를 사용합니다.

### 완료와 닫기

닫을 때 초안을 취소할지 보관할지 정하고, 닫기 버튼·Escape·외부 영역 조작에 같은 기준을 적용합니다. 일반적인 단계를 진행하려고 대화상자를 겹쳐 열지 않고 하나의 명확한 경로를 유지합니다.

> `DialogContent`는 기본으로 닫기 버튼을 제공합니다. 제품 언어에 맞게 `closeLabel`을 지정합니다. `showCloseButton={false}`로 숨긴다면 다른 보이는 종료 방법을 제공합니다. 열 때의 초점과 닫은 뒤 돌아가는 위치를 확인합니다.

</LocaleContent>

## Usage guidelines

### When to use

Use `Dialog` for a bounded task such as renaming an item or editing a few related fields. Choose inline editing when it keeps the task clear without interrupting the page. Use a dedicated page for work that needs navigation, a shareable URL, or substantial content.

### Dialog or Drawer

Choose [Drawer](/docs/components/drawer) when an edge panel suits the content and available space. Both can interrupt the page; the entry animation does not determine whether the background stays interactive. Do not switch to `Drawer` solely because a device has touch input.

Use [Alert Dialog](/docs/components/alert-dialog) when the immediate purpose is confirming a consequential action rather than editing content.

### Completion and dismissal

Decide whether closing cancels a draft or preserves it, and handle unsaved changes consistently for the close button, Escape, and outside interaction. Avoid stacking dialogs for ordinary steps; keep one clear path through the task.

> `DialogContent` includes a close button by default. Localize `closeLabel` for the product language. If hiding it with `showCloseButton={false}`, provide another visible way to exit. Check focus on entry and its return after closing.
