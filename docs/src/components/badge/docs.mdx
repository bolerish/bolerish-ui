## 사용 가이드

### 주요 속성

| 속성      | 기본값    | 값                                                        | 용도                                                    |
| --------- | --------- | --------------------------------------------------------- | ------------------------------------------------------- |
| `variant` | `primary` | `primary`, `secondary`, `outline`, `ghost`, `destructive` | 강조·보조·윤곽·최소 강조·오류 표식의 표현을 선택합니다. |

초안·보관됨처럼 유지되는 속성을 짧은 이름으로 표시합니다. 행동의 결과는 피드백 컴포넌트로 알립니다.

> 실제로 필터링할 수 없다면 정적인 배지를 필터 버튼처럼 보이게 하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### Props

| Prop      | Default   | Values                                                    | Meaning                                                          |
| --------- | --------- | --------------------------------------------------------- | ---------------------------------------------------------------- |
| `variant` | `primary` | `primary`, `secondary`, `outline`, `ghost`, `destructive` | Emphasized, supporting, outlined, minimal, or destructive label. |

Use a short label for a persistent attribute, such as Draft or Archived. Use feedback components for the result of an action.

> Do not give a static badge the appearance of a clickable filter unless it actually supports that action.

</LocaleContent>
