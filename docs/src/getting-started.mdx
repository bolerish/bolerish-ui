<LocalizedMarkdown text={"# Getting Started"} />

<LocalizedMarkdown
  text={
    "This guide adds a Button to an existing React project. Use `init --vite` for Vite; for other build tools, use `init` and configure StyleX for that build tool."
  }
/>

<LocalizedMarkdown text={"## 1. Initialize"} />

<LocalizedMarkdown text={"Run this once from the project root."} />

```bash
pnpm dlx @nuee/ui init --vite
```

<LocalizedMarkdown text={"## 2. Import alias"} />

<LocalizedMarkdown
  text={"The component and local style aliases entered during init are saved to `.nuee.json`."}
/>

```json
{
  "version": "0.6.1",
  "accessibility": {
    "respectReducedMotion": true
  },
  "aliases": {
    "ui": "@/components/ui",
    "styles": "@/styles"
  }
}
```

<LocalizedMarkdown
  text={
    "| Setting                              | Purpose                                                                                                                          |\n| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |\n| `aliases.ui` / `aliases.styles`      | The aliases used to import added components and their local StyleX tokens.                                                       |\n| `accessibility.respectReducedMotion` | Deprecated compatibility field. Copied components retain OS reduced-motion rules; only the app end user can override them at runtime. |"
  }
/>

<LocalizedMarkdown
  text={"Define the actual file locations in `tsconfig.json` or `jsconfig.json`."}
/>

<LocalizedMarkdown text={"## 3. File location"} />

<LocalizedMarkdown
  text={"The add command reads the import alias and paths to find where to save components."}
/>

```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

<LocalizedMarkdown text={"`@/components/ui` → `src/components/ui`"} />

<LocalizedMarkdown
  text={
    "> When changing an alias, also update `tsconfig.json` or `jsconfig.json`. Existing files are not moved automatically."
  }
/>

<LocalizedMarkdown text={"## 4. Add a component"} />

<LocalizedMarkdown text={"Add Button using the paths configured above."} />

```bash
pnpm dlx @nuee/ui add button
```

<LocalizedMarkdown
  text={"Import the generated component into a page. This example uses the alias from step 2."}
/>

```tsx
import { Button } from "@/components/ui/button";

export function SaveButton() {
  return <Button>Save</Button>;
}
```

<LocalizedMarkdown
  text={
    "Start your application with its existing development command. Confirm that the button appears with @nuee/ui styling and shows a focus indicator when reached with Tab. If it appears unstyled, check the StyleX build integration and reset stylesheet import."
  }
/>

<LocalizedMarkdown text={"## Installed source versions"} />

<LocalizedMarkdown
  text={
    "`.nuee.json` records the source versions copied into your project. `version` identifies the local foundation; `components` records each component installed by `add`, including registry dependencies. These values describe the installed source release, not later manual edits. Running `add` does not update the foundation version."
  }
/>

```json
{
  "version": "0.6.1",
  "components": {
    "accordion": "0.6.1",
    "button": "0.6.0"
  }
}
```

<LocalizedMarkdown
  text={
    "Older configuration files still work. Unknown foundation versions stay omitted, and external URL components are recorded as `null`. Initialization preserves existing foundation files; it only records the current release when all resulting foundation files match that release. Dry runs and canceled installations do not update the version records."
  }
/>
