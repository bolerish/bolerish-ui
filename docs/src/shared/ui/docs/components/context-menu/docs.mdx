## 사용 가이드

선택한 대상의 명령을 빠르게 여는 수단으로 사용합니다. 명령을 쉽게 발견해야 한다면 보이는 메뉴 버튼도 제공합니다.

> 보조 클릭만으로 필수 행동에 접근하게 하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Use it as a shortcut to commands for the selected target. Keep a visible menu button when those commands must be discoverable.

> Secondary click must not be the only way to reach an essential action.

</LocaleContent>
