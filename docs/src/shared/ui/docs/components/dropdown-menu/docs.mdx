## 사용 가이드

특정 항목이나 영역의 보이는 실행 컨트롤에서 엽니다. 명령 실행이 아니라 폼 값을 고르는 목적이면 `Select`를 사용합니다.

> 즉시 찾아야 하는 주요 행동은 메뉴 안에 숨기지 않습니다.

행동 그룹 사이의 구분선은 `strokeStrong`을 사용합니다. 일반 콘텐츠 구획의 `strokeDefault`보다 분명하게 구분하되, 선택·오류·포커스 표시에 대신 사용하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Open the menu from a visible trigger for a particular item or area. Use `Select` when the result is a form value rather than a command.

> Keep the main task's primary action outside the menu when people need to find it immediately.

Action-group separators use `strokeStrong` for clearer grouping than ordinary `strokeDefault` content divisions. Do not use this boundary as a substitute for selection, error or focus.

</LocaleContent>
