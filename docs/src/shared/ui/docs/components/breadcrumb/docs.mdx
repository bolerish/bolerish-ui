## 사용 가이드

실제 페이지 계층을 표시할 때 사용합니다. 현재 페이지와 상위 페이지 링크를 구분합니다.

<LocaleContent locale="en">

## Usage guidelines

Use it for a real page hierarchy. Keep the current page distinct from links to its ancestors.

> Breadcrumbs represent hierarchy, not the order of pages someone visited.

</LocaleContent>
