## 사용 가이드

### 주요 속성

| 속성      | 기본값    | 값                           | 용도                                                                  |
| --------- | --------- | ---------------------------- | --------------------------------------------------------------------- |
| `variant` | `default` | `default`, `outline`, `soft` | 그룹의 기본·윤곽·은은한 선택 표현입니다. 항목은 그룹 값을 상속합니다. |
| `size`    | `md`      | `sm`, `md`, `lg`             | 그룹 항목 크기를 선택합니다. 개별 항목에서 재정의할 수 있습니다.      |

정렬이나 서식 같은 옵션을 묶습니다. 하나만 고를지 여러 개를 고를지 먼저 정합니다.

> 익숙하지 않은 옵션을 아이콘 모양만으로 설명하지 않습니다.

`default`·`soft`는 선택 배경만 변경하고 테두리를 추가하지 않습니다. `soft`는 `bgSubtle` 묶음 안에서 `interactionSelected`를 사용합니다. `outline`만 약한 선택 경계를 유지합니다. 기본 예제는 `default`를 사용합니다. 항목의 `aria-pressed`, 비활성 선택 상태와 키보드 포커스는 유지됩니다. 연결된 패널을 바꾸려면 Tabs를 사용합니다.

</LocaleContent>

## Usage guidelines

### Props

| Prop      | Default   | Values                       | Meaning                                                                    |
| --------- | --------- | ---------------------------- | -------------------------------------------------------------------------- |
| `variant` | `default` | `default`, `outline`, `soft` | Default, outlined, or soft group treatment. Items inherit the group value. |
| `size`    | `md`      | `sm`, `md`, `lg`             | Sets item size; an item can override it.                                   |

Group choices such as alignment or formatting. Decide whether one or several selections are valid before composing the group.

> Do not rely only on an icon's appearance to explain an unfamiliar option.

`default` and `soft` change only the selected background. Soft groups use `interactionSelected` inside `bgSubtle`; only outline keeps a subtle selected edge. The basic example uses default. Items retain aria-pressed, disabled selection and independent keyboard focus. Use Tabs to switch associated panels.
