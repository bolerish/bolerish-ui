# Tooltip

Explain a compact control without adding a permanent paragraph beside it.

Use a short supplementary phrase. Use `Popover` when the content needs links, buttons, or sustained reading.

> A tooltip does not replace the control's accessible name or required instructions.

## 사용 가이드

### 사용할 때

아이콘의 동작이나 키보드 단축키처럼 컨트롤의 짧은 보조 설명에 사용합니다. 필수 안내는 페이지에 보이게 둡니다. 링크·버튼·조작이 필요하면 [Popover](/docs/components/popover)를 사용합니다.

### 내용과 접근

툴팁을 여는 컨트롤에 관한 내용을 짧고 구체적으로 씁니다. 툴팁은 접근 가능한 이름을 대신하지 않습니다. 툴팁이 있어도 아이콘만 있는 실행 컨트롤에는 `aria-label`을 제공합니다. 유용한 정보 없이 긴 이름을 그대로 반복하지 않습니다.

> 터치나 키보드 사용자에게 필요한 정보를 호버에만 의존해 전달하지 않습니다. 초점으로 표시할 수 있고 Escape로 닫을 수 있는지 확인합니다. 초점은 툴팁을 연 컨트롤에 유지하며 `TooltipContent`에 초점을 받는 컨트롤을 넣지 않습니다.

</LocaleContent>

## Usage guidelines

### When to use

Use `Tooltip` for a short, supplementary explanation of a control, such as an icon's action or keyboard shortcut. Keep required instructions visible in the page. Use [Popover](/docs/components/popover) when the content needs links, buttons, or interaction.

### Content and access

Keep the explanation brief and specific to the trigger. A tooltip does not replace an accessible name: give an icon-only trigger an `aria-label` even when a tooltip is present. Avoid repeating a long visible label without adding useful information.

> Do not rely on hover for information required by touch or keyboard users. Check focus-triggered display and Escape dismissal. Keep focus on the trigger; do not put focusable controls in `TooltipContent`.
