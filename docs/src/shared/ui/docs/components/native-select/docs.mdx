## 사용 가이드

### 주요 속성

| 속성   | 기본값 | 값         | 용도                                    |
| ------ | ------ | ---------- | --------------------------------------- |
| `size` | `md`   | `sm`, `md` | 네이티브 선택 필드의 높이를 선택합니다. |

기본 선택 동작이 폼에 맞고 팝업을 별도로 구성할 필요가 없을 때 사용합니다. 입력으로 항목을 찾아야 한다면 `Combobox`를 사용합니다.

> 열린 목록의 모양은 브라우저와 운영체제에 따라 달라집니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### Props

| Prop   | Default | Values     | Meaning                            |
| ------ | ------- | ---------- | ---------------------------------- |
| `size` | `md`    | `sm`, `md` | Controls the native select height. |

Use it when native interaction fits the form and custom popup content is unnecessary. Use `Combobox` when typing is needed to find an option.

> The popup's appearance varies by browser and operating system.

</LocaleContent>
