# 그라디언트

콘텐츠의 색을 화면의 분위기로 확장할 때 사용합니다. 기본 화면은 의미 색상 토큰을 유지하고, 앨범 아트처럼 콘텐츠가 바뀌는 영역의 배경에만 적용합니다.

## 선택 기준

| 사용 상황                   | 권장 선택                             | 선택 이유                                  |
| --------------------------- | ------------------------------------- | ------------------------------------------ |
| 음악·사진에서 가져온 분위기 | 겹친 방사형 그라디언트                | 두 색상이 한 배경 안에서 자연스럽게 이어짐 |
| 아래 콘텐츠 영역으로 연결   | `bgCanvas`로 수렴하는 선형 그라디언트 | 눈에 띄는 경계 없이 기본 표면으로 이어짐   |
| 배경 위의 긴 글·입력        | 대비를 보장하는 덮개 또는 불투명 표면 | 배경색이 바뀌어도 읽고 쓸 수 있음          |
| 떠 있는 보조 조작부         | `Card variant="translucent"`          | 배경과 연결하면서 조작 영역을 구분함       |

## 배경 조합

그라디언트는 바깥 컨테이너에 적용합니다. 카드·글자·버튼 전체에 `opacity`나 마스크를 적용하지 않습니다. 색상·위치·퍼짐을 바꾸더라도 행동·오류·선택의 의미 색상은 유지합니다.

두 개의 `radial-gradient()`로 색을 퍼뜨리고, 그 위에 기본 캔버스 색상의 덮개를 둡니다. 덮개는 아래쪽에서 캔버스로 수렴하게 해 다음 영역과 연결합니다. 실제 토큰과 동적 배경을 조합하는 전체 코드는 아래 예제에서 확인할 수 있습니다.

## 읽기와 접근성

- 일반 본문은 배경과 4.5:1 이상의 대비를 확보합니다. 큰 글자는 3:1 이상을 확인합니다.
- 두 색상이 겹친 위치와 가장 밝거나 어두운 위치를 모두 확인합니다. 대표 색상 한 곳의 대비만 확인하지 않습니다.
- 장식 레이어는 포인터 입력을 막지 않게 합니다. 긴 글과 입력은 기본 불투명 표면을 우선합니다.
- 투명도 줄이기와 강제 색상 모드에서는 장식 그라디언트를 제거하고 기본 캔버스·시스템 색상으로 복원합니다.
- 배경 모션은 필수가 아닙니다. 추가한다면 움직임 줄이기 설정을 따릅니다.
