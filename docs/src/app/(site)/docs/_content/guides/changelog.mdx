# Changelog

Read each package's release notes for changes, compatibility and migration steps. The documentation app is deployed separately from npm packages.

## Package release notes

- [@bolerish/ui](https://github.com/myjeong19/ui/blob/main/packages/ui/CHANGELOG.md): component behavior, public props and compiled styling APIs.
- [@bolerish/tokens](https://github.com/myjeong19/ui/blob/main/packages/tokens/CHANGELOG.md): shared token values and themes.

UI and tokens use a fixed release group. The Foundations lint package is independently versioned and remains private while its API is reviewed.

## Documentation updates

Docs layout and writing changes do not require an npm release. The [repository history](https://github.com/myjeong19/ui/commits/main/) records those changes alongside package work.

# 변경 기록

각 패키지의 릴리스 기록에서 변경 동작, 호환성과 이관 방법을 확인하세요. 문서 앱은 npm 패키지와 별도로 배포합니다.

## 패키지별 릴리스 기록

- [@bolerish/ui](https://github.com/myjeong19/ui/blob/main/packages/ui/CHANGELOG.md): 컴포넌트 동작, 공개 속성과 컴파일된 스타일 API.
- [@bolerish/tokens](https://github.com/myjeong19/ui/blob/main/packages/tokens/CHANGELOG.md): 공통 토큰 값과 테마.

UI와 tokens는 고정 릴리스 그룹으로 버전을 함께 올립니다. Foundations 린트 패키지는 독립적으로 버전을 관리하며 API 검토 중에는 비공개로 유지합니다.

## 문서 업데이트

문서 레이아웃과 설명 변경에는 npm 릴리스가 필요하지 않습니다. [저장소 이력](https://github.com/myjeong19/ui/commits/main/)에서 패키지 작업과 함께 확인할 수 있습니다.
