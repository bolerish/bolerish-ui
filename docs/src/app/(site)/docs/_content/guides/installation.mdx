# 설치

이 문서는 `@bolerish/ui` 0.15.0을 기준으로 합니다. 0.13.0에서 올릴 때는 패키지 변경 로그에서 `ContentRow` → `Item` 이름 변경과 아이콘 전용 버튼의 접근 가능한 이름 필수 조건을 확인하세요.

CSS 패키지 가져오기를 처리하는 빌드 도구와 React 19 앱이 필요합니다. 클라이언트 렌더링과 서버 렌더링 모두 같은 패키지와 스타일시트를 사용합니다.

## 1. 패키지 설치

React와 React DOM은 모두 패키지의 React 19 피어 의존성 범위를 충족해야 합니다. 기존 React 앱에 다음 패키지를 추가하세요.

</LocaleContent>

```package-install
npm install @bolerish/ui
pnpm add @bolerish/ui
yarn add @bolerish/ui
bun add @bolerish/ui
```

## 2. Load the stylesheet

Import once in your app's global CSS entry, before your overrides. The stylesheet includes the reset, compiled component styles, tokens and both themes. `@bolerish/ui/global.css` is also available as an explicit path.

</LocaleContent>

<LocaleContent locale="ko">

## 2. 스타일시트 가져오기

앱의 전역 CSS 진입점에서 한 번만 가져옵니다. 앱의 덮어쓰기 스타일보다 먼저 두세요. 초기화 스타일, 컴파일된 컴포넌트 스타일, 토큰과 두 테마가 포함됩니다. 명시적인 경로인 `@bolerish/ui/global.css`도 사용할 수 있습니다.

</LocaleContent>

```css
@import "@bolerish/ui";
```

<LocaleContent locale="en">

Load that global CSS from your framework's root layout or application entry. Keep it outside individual lazy-loaded pages so components and portaled menus have styles on their first render.

## 3. Render a component

Import from its package subpath. Root imports such as `import { Button } from "@bolerish/ui"` also work.

## 3. 컴포넌트 사용하기

컴포넌트별 패키지 경로에서 가져옵니다. `import { Button } from "@bolerish/ui"`처럼 루트에서 가져올 수도 있습니다.

</LocaleContent>

```tsx
import { Button } from "@bolerish/ui/button";

export function SaveButton() {
  return <Button>Save</Button>;
}
```

## 4. Choose your next step

Basic usage is ready without a StyleX build plugin. Follow [Theming](/docs/theming) to select a color mode or [Styling](/docs/styling) to customize components. You need a StyleX compiler when your own source calls `stylex.create()` or imports StyleX token definitions.

If styles are missing, confirm the global CSS is loaded by the app entry and package CSS imports are resolved by the build tool. In SSR apps, browser-dependent preferences belong in your app's server/client boundaries; the package does not choose or persist a theme for you.

</LocaleContent>

<LocaleContent locale="ko">

## 4. 다음 단계 선택하기

기본 사용에는 StyleX 빌드 플러그인이 필요하지 않습니다. 색상 모드는 [테마](/docs/theming), 컴포넌트 확장은 [스타일링](/docs/styling)을 확인하세요. 앱 코드에서 `stylex.create()`를 호출하거나 StyleX 토큰 정의를 가져올 때는 StyleX 컴파일러가 필요합니다.

스타일이 보이지 않으면 앱 진입점에서 전역 CSS를 로드했는지, 빌드 도구가 패키지 CSS 가져오기를 처리하는지 확인하세요. SSR 앱의 브라우저 의존 설정은 앱의 서버·클라이언트 경계에서 처리합니다. 패키지가 테마를 선택하거나 저장하지는 않습니다.
