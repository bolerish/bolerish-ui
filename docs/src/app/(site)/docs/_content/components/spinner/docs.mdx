<LocaleContent locale="ko">

## 사용 가이드

기다리는 행동이나 영역 옆에 짧은 상태 문구와 함께 둡니다. 완료량을 계산할 수 있으면 `Progress`를 사용합니다.

> 스피너 뒤에는 결과나 복구 방법이 있어야 합니다. 멈춘 요청을 계속 도는 표시만으로 설명하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

Place it beside the action or region that is waiting, with a brief status label. Use `Progress` when completion can be measured.

> A spinner must end in a result or recovery path; it cannot explain a stalled request indefinitely.

</LocaleContent>
