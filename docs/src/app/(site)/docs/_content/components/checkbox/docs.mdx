# Checkbox

Let people make independent choices without changing other selections.

Use a checkbox for each independent option. Use Radio Group when only one option should remain selected.

> Explain whether changes apply immediately or only when the form is submitted.

## 사용 가이드

### 사용할 때

독립적인 항목을 선택·해제하거나 그룹에서 여러 항목을 고를 때 사용합니다. 하나만 선택한다면 [Radio Group](/docs/components/radio-group), 즉시 적용되는 켜기·끄기 설정이면 [Switch](/docs/components/switch)를 사용합니다.

### 이름과 그룹

선택했을 때의 의미를 이름으로 설명합니다. 상태가 바뀌어도 이름은 유지합니다. 관련 선택지는 공통 이름으로 묶고 즉시 적용되는지 제출 후 반영되는지 알립니다.

> 가로 방향 `Field`로 체크박스와 이름을 배치합니다. 보조 설명이 있으면 `FieldContent`를 사용해 텍스트 전체가 아닌 제목 첫 줄에 맞춥니다. ID로 보이는 이름과 체크박스를 연결합니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### When to use

Use `Checkbox` for an independent choice that can be selected or cleared, or for multiple selections in a group. Use [Radio Group](/docs/components/radio-group) when exactly one option is selected, and [Switch](/docs/components/switch) for an immediately applied on/off setting.

### Labels and grouping

Describe what selecting the checkbox means. Keep that label stable when its state changes. Group related choices under a shared name and explain whether they apply immediately or on submission.

> Use a horizontal `Field` for the checkbox and label. For supporting text, use `FieldContent`; align with the title's first line rather than the whole text block. Associate the visible label with the checkbox through its ID.
