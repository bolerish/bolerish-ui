## 사용 가이드

### 주요 속성

| 속성   | 기본값 | 값               | 용도                                       |
| ------ | ------ | ---------------- | ------------------------------------------ |
| `size` | `md`   | `sm`, `md`, `lg` | 아바타와 대체 글자의 크기를 함께 바꿉니다. |

이미지가 있으면 사용하고 없으면 짧은 대체 문구를 표시합니다. 정확한 식별이 중요하면 이름도 가까이 둡니다.

> 처음 보는 사람을 아바타만으로 식별하게 하지 않습니다.

</LocaleContent>

<LocaleContent locale="en">

## Usage guidelines

### Props

| Prop   | Default | Values           | Meaning                                         |
| ------ | ------- | ---------------- | ----------------------------------------------- |
| `size` | `md`    | `sm`, `md`, `lg` | Changes avatar and fallback text size together. |

Use an image when available and a short fallback when it is missing. Keep names nearby when identification matters.

> An avatar alone is not a reliable identifier for unfamiliar people.
