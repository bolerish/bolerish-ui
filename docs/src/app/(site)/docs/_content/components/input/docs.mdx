## 사용 가이드

### 주요 속성

| 속성           | 기본값    | 값                                       | 용도                                                                    |
| -------------- | --------- | ---------------------------------------- | ----------------------------------------------------------------------- |
| `variant`      | `outline` | `outline`, `none`, `underline`, `inline` | 전체 테두리·무테·하단 선 또는 주변 글자에 맞춘 인라인 편집입니다.       |
| `disabled`     | `false`   | `boolean`                                | 입력을 막고 사용할 수 없는 상태로 표시합니다.                           |
| `aria-invalid` | `false`   | `true`, `false`                          | 유효하지 않은 값을 오류 경계로 표시합니다. 오류 설명도 함께 연결합니다. |

한 줄은 `Input`, 여러 줄은 `Textarea`, 정해진 값 중 선택은 선택 컨트롤을 사용합니다.

> 플레이스홀더는 입력하면 사라집니다. 필드 이름은 계속 보여 줍니다.

### 경계 형태 선택하기

`outline`은 기본 폼 입력입니다. `none`은 일반 입력의 크기·글꼴·안쪽 간격을
유지하면서 기본 테두리와 배경을 없앱니다. 레이블이나 주변 영역으로 입력 위치가
명확할 때 사용합니다. 키보드 초점에는 링, 오류에는 오류 윤곽선을 표시합니다.

`underline`은 하단에만 선을 두고 초점·오류도 하단 선으로 표시합니다. 초점은
높이나 배치를 바꾸지 않고 선을 강조하며, 강제 색상 모드에서는 그림자 대신
두꺼운 하단 선을 사용합니다. 전체 윤곽선은 추가하지 않습니다.

### 문장과 목록 안에서 편집하기

짧은 인라인 편집에는 `variant="inline"`을 사용합니다. 글자 크기와 색상은
주변 콘텐츠를 따르며 키보드 초점 표시와 오류 표시는 유지합니다. 여러 입력을
하나의 경계로 묶으려면 `InputGroup`을 선택합니다. 화면마다 테두리와 초점
스타일을 새로 정의하지 않습니다.

## Usage guidelines

### Props

| Prop           | Default   | Values                                   | Meaning                                                                                |
| -------------- | --------- | ---------------------------------------- | -------------------------------------------------------------------------------------- |
| `variant`      | `outline` | `outline`, `none`, `underline`, `inline` | Full border, no resting border, lower border, or typography-inheriting inline editing. |
| `disabled`     | `false`   | `boolean`                                | Prevents input and shows an unavailable state.                                         |
| `aria-invalid` | `false`   | `true`, `false`                          | Shows invalid input. Also associate a descriptive error message.                       |

Use `Input` for a single line, `Textarea` for several lines, and selection controls when values come from a fixed set.

> A placeholder disappears during entry; keep the field's name visible.

### Choose a boundary

`outline` is the default form field. `none` retains normal sizing, typography and
padding while removing the resting border and background. Use it where a visible
label or surrounding surface makes the input discoverable. Keyboard focus keeps
a ring; invalid input keeps an error outline.

`underline` places the border, focus and invalid emphasis along the bottom only.
Focus adds emphasis without changing the field's height. Forced colors use a
thicker lower border instead of a shadow, without adding a full outline.

### Editing inside text and lists

Use `variant="inline"` for short inline edits. It inherits surrounding text size
and color while retaining keyboard focus and error indications. Use `InputGroup`
when several inputs need one shared boundary.
