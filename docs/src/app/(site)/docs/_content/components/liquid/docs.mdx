## Usage guidelines

Apply `data-bolerish-surface="liquid"` to the document root or the containing region to enable refraction. Solid mode remains an opaque surface. The preview follows the site's surface setting. Liquid remains a component because it owns background layers and runtime refraction; [Gradient](/docs/foundations/gradient) is a style-only API.

Pass the decorative image or scene through `background`. Liquid renders this background once in an inaccessible, inert layer; it does not capture, clone, or automatically refract the page behind it. Keep interactive content in `children`. For an overlay, the app must supply and align its own visual background.

Use small surfaces with a uniform corner radius. The default radius uses `radiusVars.md`; change layout through `xstyle`, `className`, or `style`. There is no built-in padding. Refraction maps update on resize. Surfaces wider or taller than 1024 CSS pixels retain the material without refraction, and map generation is capped at 256 pixels on its longest side.

Reduced transparency and forced colors use an opaque surface with the decorative background hidden. Without JavaScript, canvas, or ResizeObserver, the background can remain unwarped. This component does not provide live-video refraction. Recheck text and focus contrast over the actual background in both themes; liquid does not infer an accessible foreground color from an image.

## Props

| Prop                           | Default  | Meaning                                          |
| ------------------------------ | -------- | ------------------------------------------------ |
| `background`                   | Required | Decorative content owned by this surface.        |
| `children`                     | —        | Foreground content, kept outside the SVG filter. |
| `xstyle`, `className`, `style` | —        | Style the root container.                        |

Native `div` props, including `ref` and accessible region names, reach the root.

## 사용 가이드

문서 루트나 포함 영역에 `data-bolerish-surface="liquid"`를 적용하면 굴절이 켜집니다. Solid 모드는 불투명 표면을 유지합니다. 미리보기는 사이트의 표면 설정을 따릅니다. Liquid는 배경 레이어와 런타임 굴절을 관리하므로 컴포넌트로 유지하고, 스타일만 적용하는 [Gradient](/docs/foundations/gradient/ko)는 API로 구분합니다.

장식용 이미지나 장면은 `background`로 전달합니다. 이 배경은 접근성 트리와 키보드 탐색에서 제외한 레이어에 한 번 렌더합니다. 페이지 뒤쪽을 촬영·복제하거나 자동으로 굴절시키지 않습니다. 상호작용하는 콘텐츠는 `children`에 둡니다. 오버레이에서는 앱이 시각적 배경의 내용과 정렬을 직접 관리해야 합니다.

모서리가 균일하게 둥근 작은 표면에 사용합니다. 기본 반지름은 `radiusVars.md`이며 배치는 `xstyle`, `className`, `style`로 바꿀 수 있습니다. 기본 안쪽 여백은 없습니다. 크기 변경에 따라 굴절 지도를 갱신합니다. 너비나 높이가 1024 CSS 픽셀을 넘으면 굴절 없이 재질을 유지하며 지도 해상도는 긴 변 기준 256픽셀로 제한합니다.

투명도 감소 설정과 강제 색상 모드에서는 장식 배경을 숨기고 불투명 표면을 사용합니다. JavaScript, canvas, ResizeObserver를 사용할 수 없으면 배경이 굴절되지 않을 수 있습니다. 실시간 동영상 굴절은 지원 범위에 포함하지 않습니다. 이미지에서 접근 가능한 글자색을 자동으로 추론하지 않으므로 두 테마에서 실제 배경 위의 글자·초점 대비를 확인하세요.

## 속성

| 속성                           | 기본값 | 용도                                           |
| ------------------------------ | ------ | ---------------------------------------------- |
| `background`                   | 필수   | 이 표면이 소유하는 장식 콘텐츠.                |
| `children`                     | —      | SVG 필터 밖에서 선명하게 유지하는 전경 콘텐츠. |
| `xstyle`, `className`, `style` | —      | 루트 컨테이너 스타일.                          |

`ref`와 접근성 영역 이름을 포함한 표준 `div` 속성은 루트에 전달합니다.
